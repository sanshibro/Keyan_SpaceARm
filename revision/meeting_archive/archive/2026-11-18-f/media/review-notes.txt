# F 轮组会讲解与论文衔接

**这次要回答的问题是，柔性臂在空中弯曲时，飞控能否维持机身位置？** 此前 E2 将机身固定。本轮释放机身，由 NUC 上原生 PX4 v1.13.3 的 EKF2、位置环、姿态环和角速度环控制同一套 SUPER 与 Qingyu 集成模型。一个可解除的数值夹具仅在启动和待起飞时支持飞行器。旋翼推力达到 0.98 倍模型重量时释放，在此后的 39 s 内从闭环自由飞行重建各段动作。

## 如何讲两页候选图

1. 第一页先看三个真实积分姿态，再看机身和臂角度曲线。最初的 9 s 留给起飞；随后自由悬停 5 s、向东平移 0.60 m（4 s 余弦变化和 4 s 保持），再用 14 s 弯臂并收回，最后保持 3 s。弯臂阶段机身位置指令恒定。上方相机随模型居中，世界坐标位移由曲线和视频右侧固定坐标图给出。
2. 第二页读两条位置误差和五个逐次结果。两组配对运行各改变一项 PX4 参数 MC_PITCHRATE_I，从 0.20 改为 0.40，另用 0.40 单独完成一次全日志复核。五次均用同一传感噪声种子、模型和任务。两次原设置的弯臂三维 RMS 为 17.20、17.21 cm；三次修订设置为 11.42、11.18、11.25 cm。对照的其余预登记指标均通过。这些点反映同条件重跑，统计泛化需要独立工况与种子。
3. 最终运行悬停 RMS 为 0.94 cm，平移实际 0.602 m、终点误差 1.32 cm；平移全段 RMS 为 12.29 cm，包含追赶变化指令的瞬态。弯臂定位 RMS 为 11.25 cm，瞬时最远偏离 25.07 cm。弯臂时俯仰控制的两对电机输出分开，姿态和位置扰动在收放时可见。积分增益配对支持这套模型内的位置保持改善。特定物理扰动力矩的大小仍需要独立测量。
4. 机身最大倾角 1.23°，柔性臂积分总弯曲最大 115.55°，物理步无接触。全机质量 2.25 kg，四路旋翼采用每路归一化输出乘 12 N 的标称映射，刚度与惯量采用此前的标称值。这组结果属于已知空场中的软件在环接口资格验证。摄像头建图、门洞成功率、SDK 实物柔性比映射与实飞表现都有各自的实验。

## 数据从哪里来

- 实际路径为 MuJoCo 合成 IMU、磁力计、气压计、GPS → MAVLink → PX4 EKF2 → PX4 闭环与 quad_x 混控 → 四路 HIL_ACTUATOR_CONTROLS → 四个真实 CAD 旋翼位置上的仿真推力。四通道分别映射到模型转子 3、1、0、2。模拟摇杆发送中立信号维持本机 SITL 手动链路监视。飞控只接收模拟传感器和任务指令。
- ROS1 bag 由桥接程序在运行时写入，使用仿真时钟。记录臂的请求、下发值和积分响应，位置请求、EKF 遥测、四路电机与实际施加推力；真值单列在 /f/evaluation。控制通讯使用 MAVLink，ROS 包用于证据留存。
- ULog 是 PX4 原生记录。给 PX4 启动时钟加 1,000,000 µs 即对应 HIL 和 ROS 时间。GPS 先于同一时刻的 IMU 时钟脉冲发送，这个发送顺序还可独立核对 4 ms 相位。完整评分窗口内 9,751 个 HIL tick，9,160 个共同的原生日志电机样本。共同样本的最大归一化输出差为 5.97×10⁻⁸ 以内；两个相邻 ULog 电机样本最大间隔 8 ms，原生记录器报告 0 个 dropout。交换前两个通道的负对照产生 0.286 的最大差异。
- 两次调通运行也留档。pilot01 中 PX4 收到传感器和位置请求，因缺少模拟手动链路，飞行器停留在夹具上；pilot02 接上中立模拟摇杆后飞完，但原增益的弯臂 RMS 为 16.81 cm。两者未计入五次同一记录规范的比较。

## 在研究分支重算

在已配置的 NUC 研究工作树，使用 ROS Noetic、pymavlink、pyulog、MuJoCo 3.2.3 以及现有工程依赖。启动脚本使用本机的 PX4 v1.13.3 构建目录，也可由 PX4_F_BUILD 指定。每次运行传入新的输出目录，避免覆盖已有记录。

```bash
source /opt/ros/noetic/setup.bash
export PYTHONPATH="$HOME/桌面/uav_arm_1/.mujoco_deps:$PWD/mujoco_closed_loop:$PWD/xtdrone_catkin_ws/src/uav_continuum_whole_body_v2/src:${PYTHONPATH:-}"
export MUJOCO_GL=egl OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python3 revision/scripts/round_f_sitl.py "$HOME/f_sitl_new_run" --tag independent --pitch-i .4
python3 revision/scripts/round_f_audit.py revision/data/round_f/runs "$HOME/f_sitl_new_audit"
```

git 中 revision/data/round_f/runs/ 保留两次调通和五次对照／验收的原生 ULog、ROS bag、MuJoCo 位置与速度、HIL 逐帧表、事件与控制台。早期运行的 CSV 用 gzip 无损压缩。summary.json 内 SHA-256 以解压后的字节计算。阶段网页和离线包内附最终运行的原始数据、逐次指标与两页候选图。

## 论文位置和下一轮

F 在论文中适合作为实验设置中“闭环仿真与日志验证”的依据。当前独立预览供审核。下一轮 G1 保持地图已知、固定初态和同一飞控，先让可行构型完整穿过单个门并到达门后末端目标，再公平比较直臂、固定弯臂和可变形三种策略，三者均允许机身重新规划。随后再按计划引入感知与地图不确定性。门洞净距需要由实际过门轨迹重新计算。
